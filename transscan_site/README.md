## Поведение

- Burger-меню на планшете/телефоне.
- Модальное окно по кнопкам «Связаться с нами» и «Запросить расчет».
- Hover-эффекты на кнопках, карточках, меню, партнерах, отзывах.
- Подсветка активного раздела меню при прокрутке.
- На ширине до 720px hero-картинка скрывается.
- На мобильных партнеры идут одной горизонтальной лентой.
- Форма сейчас имитирует успешную отправку. В `js/script.js` помечено место, где нужно подключить API/backend.
